Wingtip Toys - Product Catalog Application

This application demonstrates ASP.NET Web Forms architecture with master pages, routing, and product catalog management.

Features

  • Site.Master: Master Page for consistent layout and navigation.
  • Catalog/ProductList.aspx: Displays catalog items with category filtering.
  • Catalog/ProductDetails.aspx: Shows detailed specifications of selected product.
  • App_Start/RouteConfig.cs: Friendly URL Routing engine.
